The page is served at the root and at /outreach-review-pack.html. All eleven companion CSV, XLSX and
Markdown files are carried inside the page itself as data URIs, so nothing is fetched from anywhere
and no data file sits loose on the host.

To take it down: in this repository go to Settings > Pages and choose Unpublish site, or delete the
repository outright.
